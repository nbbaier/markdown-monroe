# Markdown Monroe

A glamorous markdown viewer.

## Features

- Full GFM support
- Syntax highlighting in code blocks
- Copy code blocks to clipboard
- Toggleable Table of Contents
- Two view modes: formatted and raw
- Copy to markdown to clipboard
- Light, dark, and auto (system) themes

## Usage

Navigate to any URL that returns markdown. The extension automatically dectets markdown responses and replaces the page with a nicely rendered interactive viewer with full GFM support.

- **View Picker** (Formatted / Raw) -- switch between formatted and raw markdown
- **Table of Contents** (Toggleable) -- toggle the table of contents
- **Copy Markdown** -- copy the markdown to the clipboard
- **Copy Code Blocks** -- copy code blocks to the clipboard
- **Theme** (Light / Dark / Auto) -- switch between light, dark, and auto (system) themes
